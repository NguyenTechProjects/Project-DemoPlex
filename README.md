## 1️⃣ What is Project DemoPlex?
- Windows 10 mod recreating the original Microsoft Windows Longhorn concept (2002).
- Includes official Longhorn assets ported to Windows 10.
- Recreates classic apps and icons.

## 2️⃣ Stand-out Features
- 🔒 Lock screen (wallpaper-based).
- 🟦 Longhorn Start menu & taskbar.
- 🌐 Firefox with DemoPlex skin.
- ⭐ File Explorer Favorites Bar (fully functional).
- 🎨 Icons similar to demo.
- 🖥️ Sidebar (partially decorative).
- 🎥 Windows Tour (fully working).
- 👤 Real Longhorn username (Sondra).
- 📄 Example document on desktop.
- 🖱️ Sidebar button fixed with AHK script.
- 📦 Ported old applications.
- 🔊 Fixed Longhorn sounds.
- ⚙️ Setup UI introduced.
- 🖼️ Office 2002/12 Concept (static image).
- 🔍 Windows Search, My Laptop, My Programs.
- 🟢 New Start menu & Start ORB.
- 📑 System Task/Preview Panel option working.
- ⭐ Favorites Bar items now functional.

---

## 3️⃣ Known Issues / Bugs / Missing Stuff
**Issues:**
- Low quality Start menu (intentional accuracy).
- File Explorer menubar placement limitation.
- Sidebar button is decorative only.
- Explorer may crash on low-end hardware.
- DPI scaling must be 100%.

**Bugs:**
- None discovered yet.

**Missing Stuff:**
- Office suite incomplete (static HTA placeholder).
- Sidebar button non-functional.

---

## 4️⃣ Notes
- Avoid placeholder apps in full-screen.
- Not recommended for low-end hardware.
- Windows activation required (no pre-activated software).
